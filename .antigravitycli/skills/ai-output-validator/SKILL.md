# AI 출력 데이터 검증기 (AI Output Validator)

## 개요
이 스킬은 AI 에이전트가 생성한 뉴스 요약 및 인사이트 데이터의 신뢰성을 보장합니다. Scriptly 프로젝트의 핵심 규칙인 "사실 관계 확인을 위한 출처 포함" 여부를 자동으로 검증합니다.

## 주요 검증 항목

### 1. 필수 필드 체크
- **source_url**: 원문 뉴스 링크가 반드시 포함되어야 합니다.
- **published_at**: 뉴스 발행 일시가 올바른 ISO 형식으로 포함되어야 합니다.

### 2. 데이터 정합성
- **요약 품질**: 요약 내용이 원문 뉴스(제공된 경우)의 핵심 갈등 요소를 잘 반영하고 있는지 확인합니다.
- **형식 검증**: Pydantic 모델이나 TypeScript 인터페이스와의 호환성을 확인합니다.

## 활용 방법
- AI 서비스 클래스(`CurationService`, `InsightService` 등) 개발 시 출력 결과의 유효성 검사 로직에 참고합니다.
- 테스트 코드 작성 시 Mock 데이터가 필수 필드를 포함하고 있는지 확인합니다.
