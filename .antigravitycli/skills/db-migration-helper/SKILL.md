# DB 마이그레이션 헬퍼 (DB Migration Helper)

## 개요
이 스킬은 데이터베이스 스키마의 안정적인 변경과 데이터 마이그레이션을 지원합니다. SQLAlchemy 모델과 실제 DB 간의 싱크를 맞추고, 데이터 삭제 전 백업 및 안전한 마이그레이션 절차를 가이드합니다.

## 주요 작업 가이드

### 1. 스키마 변경 (Schema Changes)
- **모델 수정**: `app/domain/models.py`에서 SQLAlchemy 모델을 수정한 후, `db-migration-helper`를 호출하여 영향을 분석하세요.
- **차이점 탐지**: 현재 DB 스키마와 모델 정의 간의 불일치를 확인합니다.

### 2. 마이그레이션 실행
- **스크립트 활용**: `scripts/` 디렉토리에 있는 기존 마이그레이션 스크립트를 우선 검토하세요.
- **안전한 실행**: 데이터를 삭제하거나 수정하는 작업 전에는 반드시 백업 스크립트를 실행하거나 스냅샷을 생성합니다.

### 3. 검증 및 복구
- 마이그레이션 후 `scripts/check_db_schema.py`를 실행하여 정합성을 확인합니다.
- 실패 시 복구 절차를 위해 `references/recovery.md`를 참고하세요.

## 프로젝트 규칙 (Scriptly)
- **데이터 삭제 금지**: 기존 데이터를 삭제해야 할 경우 반드시 백업 후 삭제합니다.
- **자동화 지향**: 가능한 한 수동 쿼리보다는 파이썬 스크립트를 통한 마이그레이션을 지향합니다.
