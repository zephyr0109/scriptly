# DB 복구 및 백업 가이드

## 데이터 백업 방법
1. **JSON 내보내기**: `scripts/` 내의 export 관련 스크립트(있을 경우)를 사용하여 데이터를 JSON 파일로 백업합니다.
2. **SQL Dump**: PostgreSQL의 `pg_dump` 명령어를 사용합니다.

## 장애 복구 절차
1. **상태 확인**: `scripts/check_db.py`를 실행하여 현재 연결 상태를 확인합니다.
2. **롤백**: 마이그레이션 실패 시, 변경 전 모델로 소스 코드를 되돌리고 백업 데이터를 복원합니다.
3. **스키마 재구성**: 최악의 경우 `scripts/recreate_db.py`를 사용하여 스키마를 처음부터 다시 생성합니다. (주의: 모든 데이터가 삭제됨)
