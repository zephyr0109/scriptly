# 드라마 구조 분석기 (Drama Structure Analyzer)

## 개요
이 스킬은 Scriptly 프로젝트의 본질인 "드라마틱한 갈등 자산 변환"을 기술적으로 지원합니다. AI가 뉴스에서 추출한 정보가 실제 드라마 작법에 적합한 구조를 갖추고 있는지 분석합니다.

## 주요 분석 가이드라인

### 1. 인물 분석 (Character Map)
- **욕망과 결핍**: 인물에게 명확한 '욕망(Want)'과 '결핍(Need)'이 부여되었는지 확인합니다.
- **내적/외적 갈등**: 뉴스 속 인물의 대립 관계가 드라마틱한 갈등으로 치환되었는지 분석합니다.

### 2. 구조 분석 (Plot Structure)
- **3막 구조**: 사건의 발단, 전개(위기/절정), 결말이 논리적으로 연결되는지 확인합니다.
- **텐션 스코어링**: `CurationService`에서 사용하는 텐션 측정 기준이 드라마틱한 재미를 충분히 보장하는지 검토합니다.

## 작업 원칙
- **사실 기반 창작**: 원문 뉴스의 사실 관계를 훼손하지 않으면서 드라마틱한 가능성을 확장합니다.
- **작가 중심**: 분석 결과는 작가에게 영감을 줄 수 있는 전문 용어(예: 서브텍스트, 앙갚음, 아이러니 등)를 사용하여 전달합니다.
