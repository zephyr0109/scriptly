# 한글 웹 접근성 체크기 (Korean A11y Checker)

## 개요
이 스킬은 Scriptly의 UI가 모든 사용자(특히 비기술자 작가)에게 친숙하고 접근 가능하도록 보장합니다. 한국어 웹 환경의 특수성과 표준 접근성 가이드라인을 동시에 체크합니다.

## 주요 체크 항목

### 1. 한글 UI 규칙
- **텍스트 일관성**: 버튼, 레이블, 메시지 등에서 한글 사용이 일관된 어투(예: '하십시오' vs '해요')를 유지하는지 확인합니다.
- **누락 확인**: UI 요소 중 번역되지 않은 영어 텍스트가 남아있는지 탐지합니다.

### 2. 웹 접근성 (A11y)
- **대체 텍스트**: 이미지나 아이콘에 적절한 한글 대체 텍스트(`alt`, `aria-label`)가 있는지 확인합니다.
- **색상 대비**: 가독성을 위한 충분한 색상 대비가 확보되었는지 체크합니다.

## 작업 원칙
- **작가 친화적**: 기술적인 에러 메시지보다는 사용자가 이해하기 쉬운 한글 메시지로 가이드합니다.
