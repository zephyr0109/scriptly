# React Hook 오디터 (React Hook Auditor)

## 개요
이 스킬은 React 컴포넌트 개발 시 발생하기 쉬운 Hook 관련 오류를 방지합니다. 특히 `useMemo`, `useEffect`, `useCallback`의 의존성 배열 누락을 정밀하게 감사하며, Scriptly 프로젝트의 프론트엔드 코딩 원칙 준수 여부를 확인합니다.

## 주요 감사 항목

### 1. 의존성 배열 (Dependency Arrays)
- **누락 확인**: Hook 내부에서 사용되는 모든 외부 변수, 함수, Props가 `deps` 배열에 포함되어 있는지 확인합니다.
- **불필요한 의존성**: 불필요하게 포함되어 렌더링 성능을 저하시키는 의존성을 제거하도록 제안합니다.

### 2. 스코프 및 선언 순서
- **정의 위치**: Hook이 조건문이나 반복문 내부가 아닌 최상위 레벨에서 선언되었는지 확인합니다.
- **변수 참조**: Hook이 참조하는 변수가 Hook 선언 이전에 올바르게 정의되었는지 확인합니다.

### 3. 컴포넌트 아키텍처
- **서버/클라이언트 분리**: `'use client'` 지시어가 필요한 곳에 적절히 사용되었는지, 서버 컴포넌트에서 클라이언트 전용 기능을 사용하지 않는지 감사힙니다.

## 작업 원칙
- **엄격한 타입 체크**: `any` 사용을 금지하며, 인터페이스 정의 여부를 확인합니다.
- **가독성**: 복잡한 Hook 로직은 커스텀 Hook으로 분리하도록 제안합니다.
- 상세 체크리스트는 `references/checklist.md`를 참고하세요.
