# v3에서 v4로의 마이그레이션 핵심 요약

## 1. 설정 파일 제거
- `tailwind.config.js` 또는 `tailwind.config.ts` 파일을 삭제(또는 CSS로 이전)할 수 있습니다.
- 모든 설정은 CSS 파일의 `@theme` 블록으로 옮겨집니다.

## 2. 엔진 변경
- v4는 Rust로 작성된 새로운 엔진(Oxide)을 사용합니다.
- 별도의 PostCSS 플러그인이 필요 없을 수도 있으며, Vite/Next.js 플러그인으로 대체됩니다.

## 3. 브라우저 CDN 지원
- `@tailwindcss/browser` 패키지를 통해 별도의 빌드 과정 없이 브라우저에서 v4 런타임 엔진을 실행할 수 있습니다.
- 개발 단계에서 매우 유용합니다.

## 4. 유틸리티 클래스 변경 사항
- 대부분의 v3 클래스는 호환되지만, 일부 복잡한 커스텀 설정은 CSS 변수 기반으로 다시 정의해야 할 수 있습니다.
