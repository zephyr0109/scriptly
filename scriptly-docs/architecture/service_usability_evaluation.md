# Scriptly 서비스 사용성 및 도메인 유효성 평가 보고서 (v1.0)

드라마 작가의 창작 라이프사이클에 맞추어 **Scriptly** 서비스가 실제로 사용 가능한 도구인지, 드라마 작가로 빙의(Role-play)하여 실사용자 관점에서 본질적인 유효성을 평가한 보고서입니다.

---

## 🎭 1. 드라마 작가의 가상 실사용 시나리오 평가

### A. 기획안 작성 및 발상 단계 (영감 검색 & 스크랩)
* **긍정적 요인 (유효성)**:
  * 실제 기사에서 극작 갈등 요소(`Dramatic Tension`)와 인물별 `욕망(Desire)`을 짚어내어 시각화해 주는 기능은 사회파 드라마나 전문직물을 집필하는 작가에게 최고의 브레인스토밍 동반자입니다.
  * **원문 우선 로딩 탭 개편** 덕분에, AI 로딩 대기 시간 동안 기사 원문을 먼저 읽으며 창작 발상을 즉각 시작할 수 있게 되어 집필 리듬이 끊기지 않습니다.
* **불편한 점 (개선 과제)**:
  * 스크랩된 기사가 많아질 경우, 에피소드별이나 에셋 분류별 **"폴더 관리(분류)"** 기능이 미약하여 나중에는 스크랩 정보가 뒤섞여 찾기 힘들어질 수 있습니다.

### B. 캐릭터 빌딩 및 인물 관계도 (Character & Canvas)
* **긍정적 요인 (유효성)**:
  * 기사에서 캐릭터의 내적 욕망과 대립각을 자동으로 추출해주어 인물 관계의 뼈대를 손쉽게 잡을 수 있습니다.
  * 드래그앤드롭 기반의 인물 관계도(Canvas Board)는 한눈에 세력 구도와 인물의 밀고 당기는 관계를 정리할 수 있어, 장편 드라마 구상 시 머릿속 꼬인 타래를 푸는 데 매우 효과적입니다.
* **불편한 점 (개선 과제)**:
  * 컴퓨터 조작이 미숙한 비기술자 작가에게는 마우스로 노드(카드)를 생성하고 마우스 드래그로 선(엣지)을 잇는 캔버스 조작법 자체가 다소 귀찮거나 어렵게 느껴질 수 있습니다.
  * AI가 인물 관계를 추출한 뒤 **"인물 관계도 초안 자동 배치"** 버튼을 제공하여 원클릭으로 캔버스 판을 짜주는 마법 같은 동선이 추가된다면 유효성이 훨씬 더 급상승할 것입니다.

### C. 세계관 설정실 (World-Building)
* **긍정적 요인 (유효성)**:
  * 시공간 무대, 세력, 문화 규칙, 사전(Glossary)은 판타지나 SF, 역사극, 전문직물 등을 그릴 때 작가의 뇌를 백업하는 장치 역할을 확실히 해줍니다.
  * `Soft Relation(느슨한 연결)` 덕분에 특정 설정이 지워져도 다른 집필 에셋이 망가지지 않아 자유로운 변경이 가능합니다.
* **불편한 점 (개선 과제)**:
  * 시공간 무대 계층이나 세력 설정이 다소 문서 입력 위주로 단조롭게 배치되어 있어, 세계관 간의 논리적 모순이나 빈틈을 시각적으로 모니터링할 수 있는 **"세계관 연결 맵"** 또는 **"연관성 그래프 대시보드"**가 향후 필요합니다.

### D. 대본 에디터 (Script Editor)
* **긍정적 요인 (유효성)**:
  * 프로젝트 기획 정보, 인물 카드, 세계관 사전을 우측 보조 패널(참고 책장)로 띄워두고 한 화면에서 대본을 집필할 수 있는 올인원 작업 공간은 작가들에게 로망과 같은 편리한 레이아웃입니다.
* **불편한 점 (개선 과제 - 치명적)**:
  * 대본은 **지문, 대사, 캐릭터 이름 표시, 씬 넘버링(S#)** 등 한국 극작계 고유의 매우 엄격한 정형 레이아웃 규칙을 따릅니다.
  * 현재의 에디터가 단순히 자유 텍스트 입력창 수준에 머물러 있다면, 작가들은 기존에 익숙한 아래한글(HWP)이나 전문 시나리오 에디터(Scrivener, Fade In 등)의 단축키/포맷팅 편의성을 이기지 못하고 이탈할 것입니다.
  * `Tab` 키 클릭 시 [인물이름]과 [대사] 입력을 빠르게 스위칭해 주는 **극본 전용 단축 매크로 에디팅 기능**의 탑재가 서비스의 사활을 쥐고 있습니다.

## 🎯 2. 프로젝트 영역별 기능의 실용성 진단

| 영역명 | 작가용 실용성 | 불필요 요소 / 사족 여부 | 한 줄 진단 |
| :--- | :---: | :---: | :--- |
| **기획 정보** | **최상** | 없음 | 로그라인과 기획의도를 항상 리마인드하며 산으로 가지 않게 잡아줌. |
| **캐릭터** | **최상** | 없음 | 드라마의 엔진은 인물이므로 필수. 단, 캔버스 조작의 장벽을 낮춰야 함. |
| **플롯(사건)** | **상** | 없음 | 사건 타임라인 배치는 씬 구성에 유용하나, 기획안 연동성이 더 긴밀해야 함. |
| **시놉시스** | **중상** | 없음 | 전체 줄거리를 줄글로 적는 공간. 단순 Textarea로도 충분하나 AI 요약이 절실함. |
| **대본 에디터** | **최하** (개선 전) | 없음 | 현재는 단순 텍스트 편집기 수준. **대본 표준 포맷 자동 적용**이 안 되면 무용지물. |
| **세계관 설정** | **상** | 약간 복잡함 | 비장르물 작가에게는 입력 폼이 과하게 세분화되어 있어, 숨기기/축소 뷰 지원 필요. |

## 🛠️ 3. 서비스 관점의 최우선 개선 제안 (작가 친화적 UX)

1. **대본 전용 마크업/자동 단축 포맷 에디터 도입**
   * 에디터 내에서 `S#` 입력 시 자동 번호 매기기, `Tab` 키로 인물명과 대사 서식 스위칭, 인쇄 시 대본 표준 포맷 PDF 출력 보장 등을 최우선 탑재해야 기성 작가들을 Lock-in할 수 있습니다.
2. **AI 기반 인물 관계도 캔버스 초안 자동 렌더러**
   * 작가가 하나하나 마우스로 인물 카드를 배치하지 않고, AI의 상세 분석 결과 목록에 있는 관계 정보를 읽어와 캔버스 노드로 배치 정렬을 90% 완성해주는 기능을 추가하여 캔버스 사용 장벽을 극단적으로 허물어야 합니다.
3. **영감 스크랩 태깅 및 스마트 폴더**
   * 보관한 영감 뉴스가 어떤 캐릭터에 매칭되는지, 어떤 에피소드용인지 분류할 수 있도록 **해시태그 기능 및 폴더 트리**를 강화해 관리 효율성을 극대화해야 합니다.
